DSH 插件策划 · v1.0

设计台 · 室内设计师个人工作台

把设计师的全流程业务收进一条项目管线：客户从线索到结项只有一条主线，今天该干的事自动浮到最上面， 效果图直接在插件里调本机 ComfyUI 出，副业与娱乐隔到另一个 Tab。

需求解码：11 件事 → 4 条链

模块不是按「事情」切的，是按「链」切的 —— 这是整个方案的地基

A · 获客转化链

客户资料 · 预约量房 · 对接需求 · 方案 · 报价 · 签合同 · 预约到店 · 选材
坑：报价发出去没回音，该回访时忘了

B · 交付链

效果图 · PPT 汇报 · 工地进度 · 材料进场 · 全网找参考图
坑：找图出图吃掉 3-4 小时；工地节点靠脑子记

C · 创作链

每天更新公众号文章 · 写小说
坑：断一天就断一周

D · 补给链

听 QQ 音乐 · 看小说 · 阅读电子书
坑：被「管理感」破坏，最后干脆不用

三条核心设计判断

判断 1
主轴是「项目管线」，不是待办清单
所有事情都是某个客户项目的派生物。数据主键是项目，待办是它的自动产物 —— 让「不漏跟进」从靠记性变成靠结构。
判断 2
贵的是「找图」和「出图」
一天隐性吃掉 3-4 小时。必须有效果图工坊（接本机 ComfyUI）+ 素材库，把翻浏览器压成填三个字段点一下。
判断 3
副业与娱乐物理隔离
公众号/小说是「生产」，听歌/读书是「消费」。消费进主工作台会污染专注度 —— 独立 Tab，且只做轻入口。

业务阶段模型：9 段「推一下就走」

每段绑定「标准动作 → 交付物 → 自动排出的下一个待办」，这就是工作台的引擎
01
线索
记录客户资料 / 需求 / 预算
→ 预约量房 +1天
02
量房
量尺 + 拍照 + 现场确认
→ 出平面方案 +2天
03
方案设计
平面 → 效果图 → 汇报 PPT
→ 出报价 +1天
04
报价
报价单、发送、跟进
→ 跟进回访 +2天
05
签约
合同 + 收款计划
→ 预约到店选材 +1天
06
选材深化
陪同选材、确认主材
→ 材料下单 +1天
07
施工
节点巡检 水电/瓦/木/油/安
→ 下次巡检 +3天
08
安装验收
安装、验收、整改
→ 结项 +2天
09
结项回访
回访、要转介绍
→ 口碑 / 案例
核心体验
用户只需要点「推进到下一阶段」，不用自己想下一步该干嘛 —— 系统按这张表自动排出标准动作。

第 1 期详细设计

本期实际交付的 3 个模块
M1 · 项目管线看板
  • 看板视图：9 阶段分列卡片墙，显示 客户·小区房号·阶段·下次行动·倒计时，逾期红标，可拖拽换阶段
  • 列表视图：按阶段 / 最近联系 / 金额 / 倒计时排序
  • 客户档案抽屉：电话、微信、小区、户型、面积、风格偏好、预算、家庭成员、禁忌项、沟通流水
  • 新建项目 3 步：客户资料 → 房屋信息 → 需求；创建即自动生成「预约量房」待办
  • 一键推进阶段：记流水 + 自动排下一阶段标准待办
M2 · 今日作战台
落地页最上方，四个分区按优先级排列：
逾期 — 一键完成 / 顺延到明天
今天 — 量房/到店/巡检/材料/回访
三天内 — 避免突然爆雷
沉默项目唤醒 — 报价后 N 天没跟进
昨天没做完的自动滚到今天，绝不凭空消失
M3 · 效果图工坊
  • 入口一：项目卡片「出效果图」→ 自动带入该项目风格偏好与户型
  • 入口二：命令 /出图 金地花园-1201 客厅 奶油风 无主灯
  • 参数面板：空间 / 风格 / 材质关键词 / 光照 / 比例 / 张数 / 种子
  • 结果墙：缩略图网格 → 设为方案主图 / 加入 PPT / 换种子重出
  • 自动归档：renders/{项目}/{日期}/，绑定项目

ComfyUI 集成方案

工作台不重复造 ComfyUI，只做它不做的两件事：注入项目上下文 + 归档结果回项目

参数注入的两种方式

方式做法优点缺点
A · 按节点 ID 注入
推荐		 设置面板配置：正向提示词节点 ID、种子节点 ID、宽高节点 ID、（可选）输入图节点 ID 用户不用改工作流，最稳 要去 ComfyUI 界面查一次节点编号
B · 占位符替换
兜底		 用户把工作流里的提示词写成 {{prompt}}，导出后插件做字符串替换 配置最简单 需要用户改工作流，节点一改就失效
必须避开的坑
  • 工作流必须是「API 格式」 —— ComfyUI 界面右上角 Workflow → Export (API)，普通 UI 格式 JSON 无法提交给 /prompt。这是踩坑率最高的一点。
  • ComfyUI 与 DSH 必须同机或网络互通，默认地址 http://127.0.0.1:8188。
  • 出图是长任务（30 秒 ~ 5 分钟），接口必须返回 prompt_id 后异步轮询，不能同步阻塞等待。

降级策略（不崩原则）

情况表现
ComfyUI 未启动按钮置灰 + 提示「ComfyUI 未连接，点击查看启动方式」，其余模块照常可用
未配置工作流引导式弹窗：教用户导出 API 格式 JSON + 填节点 ID
出图失败保留 prompt 参数，给「重试」按钮，不丢用户输入
网络断开项目 / 客户 / 待办等主业务数据完全不受影响（本地存储）

数据存储与安全

资料库云端能力经检测不可用 → 本期采用本地方案
目录结构 
~/.designer-desk/
├── data.json       主库（11 张表）
├── data.bak.json   滚动备份
├── config.json     配置
└── renders/        效果图归档
    └── {项目}/{日期}/
数据安全四件套
  • 每次写入前自动滚动备份到 data.bak.json
  • 首屏提供「导出 JSON 备份」「导入恢复」（不藏进设置里）
  • 清空数据需二次确认弹窗
  • 数据积累到 30 条时顶部温和提示备份

风险与降级

风险影响对策
工作流格式不对（非 API 格式）出图全流程失败设置面板内置图文引导 + 提交前校验 prompt 字段
文件系统写入权限数据无法持久首次启动自检目录可写，失败则引导改目录
Node half 变更不生效改完没反应改 src/ → pnpm run bundle → 重启 web（ESM 缓存不热更）
模块越加越多导致失焦用不起来严格执行分期，每期 ≤3 模块
公众号自动发布微信个人号无开放接口定位「日更台」：选题库 + 发布日历 + 草稿 + 一键复制，不承诺自动发布
QQ 音乐 / 阅读无合法 API定位「轻入口」：本地唤起客户端 + 记录在听 / 在读，不做数据抓取
